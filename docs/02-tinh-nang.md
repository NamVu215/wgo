# 02 – Danh sách tính năng WGo

_Cập nhật lần cuối: 2026-09-15._

> **Trạng thái:** đã làm xong giai đoạn 1 (lõi) và giai đoạn 2 (bản đồ, gần tôi, "hôm nay ăn gì?", PWA, offline, ảnh, ngày nghỉ âm lịch). Chi tiết: [07, mục 7–8](07-huong-dan-chay-va-dua-len-mang.md#7-đã-có-trong-giai-đoạn-1). Bảng dưới là danh sách ban đầu.

Ký hiệu: 🟢 dự kiến có trong bản đầu (MVP) · 🟡 nên có sớm · 🔵 tiềm năng về sau · ⚙️ cần backend hoặc dịch vụ ngoài

## 1. Tìm & gợi ý

| Tính năng | Mức |
|---|---|
| Chọn thành phố (bản đầu chỉ có Huế) | 🟢 |
| Lọc theo khu vực, loại địa điểm, món, mức giá | 🟢 |
| Lọc "đang mở cửa" theo giờ hiện tại | 🟢 |
| Tìm kiếm theo tên quán / tên món | 🟢 |
| Sắp xếp theo rating | 🟢 |
| Nút "Hôm nay ăn gì?": bốc ngẫu nhiên quán hợp bộ lọc | 🟡 |
| Gần tôi: sắp xếp theo khoảng cách GPS | 🟡 |
| Bản đồ hiển thị các quán | 🟡 |
| Gợi ý theo buổi: sáng (bún bò, bánh canh), tối (chè, ốc)… | 🟡 |
| Gợi ý lịch trình: ăn → cafe → dạo chơi gần nhau | 🔵 |
| Gợi ý theo thời tiết (mưa thì chỗ có mái che) | 🔵 |

## 2. Thông tin quán

| Tính năng | Mức |
|---|---|
| Trang chi tiết: địa chỉ, giờ mở cửa, giá, món nên gọi, mẹo | 🟢 |
| Nút chỉ đường (mở Google Maps) | 🟢 |
| Rating + nhận xét riêng | 🟢 |
| Tag: local, view đẹp, hẹn hò, bình dân… | 🟢 |
| Ảnh quán | 🟡 |
| Rating riêng từng người (hai bạn chấm khác nhau) | 🟡 |
| Link TikTok/Facebook review | 🔵 |

## 3. Cá nhân (lưu trên từng máy)

| Tính năng | Mức |
|---|---|
| Yêu thích ❤️ | 🟢 |
| Đánh dấu "đã đi" / "muốn đi" | 🟡 |
| Ghi chú riêng | 🔵 |
| Đồng bộ giữa hai điện thoại | 🔵 ⚙️ |

## 4. Dữ liệu & quản lý

| Tính năng | Mức |
|---|---|
| Dữ liệu quán lưu trong file đi kèm web | 🟢 |
| Nhập dữ liệu từ Google Sheets | 🟡 |
| Trang "Thêm quán" trong web | 🔵 ⚙️ |
| Người dùng khác gửi đề xuất quán, chủ web duyệt | 🔵 ⚙️ |

## 5. Trải nghiệm

| Tính năng | Mức |
|---|---|
| Giao diện ưu tiên điện thoại | 🟢 |
| Cài lên màn hình điện thoại như app (PWA) | 🟡 |
| Dùng được khi mạng yếu hoặc mất mạng | 🟡 |
| Dark mode | 🔵 |
| Tiếng Anh cho khách nước ngoài | 🔵 |
| Chia sẻ link quán / danh sách qua Zalo, Messenger | 🟡 |

## 6. Mở rộng & cộng đồng (tính sau)

| Tính năng | Mức |
|---|---|
| Thêm Đà Nẵng, Nha Trang, Vũng Tàu, TP.HCM, Thủ Đức | 🔵 |
| Bộ sưu tập "Top 10 quán chè Huế", "Cafe view sông Hương"… | 🔵 |
| Góc cho khách nước ngoài: cách gọi món, giá hợp lý, tránh bị "chặt chém" | 🔵 |
| Đăng nhập, đánh giá cộng đồng | 🔵 ⚙️ |
| Quảng cáo / quán được đề xuất | 🔵 ⚙️ |
